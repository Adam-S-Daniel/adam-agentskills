# Purpose — compare-pdfpairs

Maintenance context only; never loaded at inference.

## What it is for

Compares each name.pdf with its suffixed twin (for example "-signed" or "-needsocr") to tell whether they print identically and whether their embedded text differs, so redundant duplicates can be deleted safely.
